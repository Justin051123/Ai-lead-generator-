## 2025-02-14 - Parallel I/O and Regex Compilation Optimization
**Learning:** Sequential web scraping of lead URLs with artificial delays (`time.sleep(1)`) represents a massive performance bottleneck. Switching to parallelized execution using `concurrent.futures.ThreadPoolExecutor` with `executor.map` preserves search result ordering while eliminating sequential waiting times. Additionally, compiling the regular expression once at the module level rather than on every function execution avoids redundant CPU overhead during batch processing.
**Action:** Always pre-compile regex patterns for repeated/batch matching tasks, and use `ThreadPoolExecutor` for handling multiple concurrent network/scraped I/O bound tasks to maximize throughput. Use `executor.map` specifically when maintaining input/relevance ordering is critical.
