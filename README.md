# AI Lead Generator 🚀

A simple yet powerful tool to find business leads using Google Search and web scraping.

## Features
- **Search by Niche and Location**: Find relevant businesses quickly.
- **Automated Web Scraping**: Extracts page titles and emails.
- **AI Qualification (Placeholder)**: Scores leads based on extracted data.
- **CSV Export**: Download your leads for easy outreach.

## Setup
1. Install dependencies:
   ```bash
   uv sync
   ```
2. Run the application:
   ```bash
   uv run streamlit run app.py
   ```

## Technologies
- [Streamlit](https://streamlit.io/)
- [BeautifulSoup4](https://www.crummy.com/software/BeautifulSoup/)
- [googlesearch-python](https://pypi.org/project/googlesearch-python/)
- [Pandas](https://pandas.pydata.org/)
